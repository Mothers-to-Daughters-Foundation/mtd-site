# News Content Rip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/news` faithfully mirror the live newsroom — verbatim intro + hero image, and all 13 real articles ripped into MDX with full bodies rendered at `/news/[slug]`.

**Architecture:** Reuse the existing MDX pipeline (`src/lib/mdx.ts`: `getAllNews`, `getNewsBySlug`) and routes (`src/app/(site)/news/page.tsx`, `src/app/(site)/news/[slug]/page.tsx`). Add an intro/hero block to the list page; add 13 `content/news/*.mdx` files whose bodies are transcribed from the live article pages via WebFetch.

**Tech Stack:** Next.js 14 App Router, TypeScript, `gray-matter` MDX, `next/image`, WebFetch (content), curl (image download).

## Global Constraints

- Intro copy is VERBATIM from the spec (headline "Stay Inspired. Stay Informed.", the "What You'll Find Here" four bullets, and the closing "We're not just telling stories…" line).
- 13 articles, clean readable slugs (NOT the Wix URL-encoded form), ISO dates (`YYYY-MM-DD`), newest-first (the pipeline sorts).
- Images are downloaded into `public/images/news/`, never hotlinked from Wix. The live list thumbnails are all Wix `Image-empty-state` placeholders, so article cards get NO `image` frontmatter (they use the card's existing placeholder); only the hero is downloaded.
- Do not change `src/lib/mdx.ts` interfaces or shared components beyond the `/news` list page + a new news-scoped CSS module.
- JSX text must escape apostrophes (`&rsquo;`) and ampersands in copy to satisfy `react/no-unescaped-entities` (a clean `tsc` does NOT catch this; it fails `next build`).
- The pre-existing `content/news/intergenerational-mentoring-program-open.mdx` is legitimate M2D content — KEEP it (do not delete). Final news count is therefore 14 (13 ripped + 1 existing).
- Verify with `npx tsc --noEmit`; run `npx next build` only after stopping any live dev server.
